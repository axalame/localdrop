# LocalDrop

Локальный сервис для синхронизации буфера обмена и безопасной передачи файлов между рабочими станциями (Windows, macOS, Linux) и мобильными устройствами (iOS, Android) по локальной сети Wi-Fi/Ethernet.

Приложение не требует доступа к внешнему интернету, сторонних облачных сервисов или установки сторонних приложений на подключаемые устройства: достаточно открыть локальный IP-адрес хоста в любом современном браузере.

## Технологический стек

- **Десктопное ядро:** Tauri v2, Rust 1.78+, WebView2.
- **Встроенный HTTP & WebSocket сервер:** Axum 0.8, Tokio, Tower-HTTP.
- **Криптографический модуль:** X25519 ECDH (`x25519-dalek`), HKDF-SHA256 (`hkdf`, `sha2`), XChaCha20-Poly1305 AEAD (`chacha20poly1305` на бэкенде, `@noble/ciphers` на фронтенде).
- **Интерфейс десктопа и веб-клиента:** React 19, TypeScript, Tailwind CSS v4, Vite, Lucide Icons.
- **Встраивание ассетов:** `rust-embed` (веб-клиент компилируется непосредственно в бинарный файл Windows).

## Основные функциональные возможности

- **Синхронизация буфера обмена (ПК-на-ПК и ПК-на-Смартфон):**
  - Перехват изменений системного буфера через OS API (`arboard`), мгновенное вещание по шифрованному WebSocket всем подключенным узлам в локальной сети.
  - Мгновенная отправка текста с любого подключенного устройства (смартфон, ноутбук, другой ПК) в системный буфер хоста без задержек.
- **Сквозное транспортное шифрование (XChaCha20-Poly1305 AEAD):**
  - При установке WebSocket-соединения выполняется диффузный обмен ключами по протоколу X25519 ECDH с формированием сессионного симметричного ключа через HKDF-SHA256.
  - Каждое передаваемое сообщение шифруется алгоритмом XChaCha20-Poly1305 с уникальным 24-байтным CSPRNG nonce и криптографическим тегом аутентификации Poly1305, предотвращающим перехват и модификацию трафика в локальной сети.
- **Группировка и фильтрация контента:**
  - Левая панель группировки:
    - **Все** и **Избранное** (с возможностью добавления в избранное по клику на звездочку).
    - **Тип:** Текст, Форматированный текст, Изображение, Файл.
    - **Тег:** Ссылка, Код, Изображение (с автоматической классификацией содержимого).
    - **Источник:** фильтрация по конкретному устройству-отправителю или общему направлению.
    - **Время:** За все время, Сегодня, Вчера, За 7 дней.
- **Передача и предпросмотр файлов:**
  - Потоковая загрузка (streaming) файлов любого размера без буферизации всего содержимого в оперативной памяти.
  - Автоматическое сохранение в директорию `Downloads/LocalDrop` на стороне Windows.
  - Защита от Path Traversal, проверка канонических путей и очистка имен файлов от спецсимволов и зарезервированных имен Windows.
  - Полноразмерный модальный просмотр изображений и встроенное воспроизведение медиа.
- **Автономность:**
  - Полное встраивание скомпилированного фронтенда в исполняемый файл `localdrop.exe`. Для работы веб-интерфейса на смартфонах и других ПК не требуется установка стороннего ПО.
- **Сохранение состояния:**
  - Ограниченный циклический буфер истории (до 100 последних записей) с сериализацией в `history.json`.

### Спецификация API

- `GET /` — Загрузка встроенного одностраничного веб-приложения (SPA).
- `GET /ws` — Защищенное WebSocket-соединение с процедурой `handshake_init` / `handshake_ack` и передачей зашифрованных фреймов `encrypted_envelope`.
- `GET /api/status` — Получение текущего состояния сервера, локального IP, портов и списка подключенных узлов.
- `GET /api/history` — Получение последних записей буфера обмена и переданных файлов с метаданными.
- `POST /api/history/favorite` — Переключение статуса избранного для указанной записи истории (`{"id": "..."}`).
- `POST /api/history/clear` — Полная очистка истории обмена.
- `POST /api/clipboard` — Запись текста в системный буфер обмена хоста.
  - Тело запроса: `{"text": "строка"}`
  - Заголовок: `Content-Type: application/json`
- `POST /api/upload` — Потоковая загрузка файла (`multipart/form-data`).
- `GET /api/view/:id` — Просмотр файлов и изображений в браузере.
- `GET /api/download/:id` — Скачивание файла с поддержкой Range-запросов (HTTP 206 Partial Content).

## Сборка и запуск

### Системные требования

- **Node.js** версии 20 или выше
- **Rust & Cargo** версии 1.78 или выше

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

Для запуска десктопного приложения в режиме разработки с горячей перезагрузкой:

```bash
npm run build
npm run tauri:dev
```

### Сборка исполняемого файла

Сборка оптимизированного автономного бинарного файла и установщика для Windows:

```bash
npm run build
npm run tauri:build
```

Результаты сборки размещаются в каталоге:
- Автономный бинарный файл: `src-tauri/target/release/localdrop.exe`
