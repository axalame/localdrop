# LocalDrop

Локальный сервис для синхронизации буфера обмена и передачи файлов между мобильными устройствами (iOS Safari, Android Chrome) и рабочей станцией Windows по локальной сети Wi-Fi.

Приложение не требует доступа к внешнему интернету, сторонних облачных сервисов или установки мобильных приложений из App Store и Google Play.

## Технологический стек

- **Десктопное ядро:** Tauri v2, Rust 1.78+, WebView2.
- **Встроенный HTTP & WebSocket сервер:** Axum 0.8, Tokio, Tower-HTTP.
- **Интерфейс десктопа и веб-клиента:** React 19, TypeScript, Tailwind CSS v4, Vite.
- **Встраивание ассетов:** `rust-embed` (веб-клиент компилируется непосредственно в бинарный файл Windows).

## Основные функциональные возможности

- **Синхронизация буфера обмена:**
  - Направление Windows -> Мобильное устройство: перехват изменений системного буфера через OS API (`arboard`), мгновенное вещание по WebSocket клиентам в локальной сети.
  - Направление Мобильное устройство -> Windows: отправка текста через веб-интерфейс или посредством прямого HTTP POST-запроса через iOS Shortcuts (Команды). Текст записывается в системный буфер Windows без задержек.
- **Передача файлов:**
  - Потоковая загрузка (streaming) файлов любого размера без буферизации всего содержимого в оперативной памяти.
  - Автоматическое сохранение в директорию `Downloads/LocalDrop` на стороне Windows.
  - Защита от Path Traversal, проверка канонических путей и очистка имен файлов от спецсимволов и зарезервированных имен Windows.
- **Автономность:**
  - Полное встраивание скомпилированного фронтенда в исполняемый файл `localdrop.exe`. Для работы веб-интерфейса на смартфонах не требуется присутствие Node.js или исходных файлов на компьютере.
- **Сохранение состояния:**
  - Ограниченный циклический буфер истории (до 100 последних записей) с сериализацией в `history.json`.

```
|             |                               |               |
|             +------------+   +--------------+               |

|                   +------v---v------+                       |

+----------------------------^--------------------------------+

|  - Mobile Safari / Chrome (Embedded SPA Web Client)         |

```

### Спецификация API

- `GET /` — Загрузка встроенного одностраничного веб-приложения (SPA).
- `GET /ws` — WebSocket-соединение для двусторонней синхронизации событий реального времени.
- `GET /api/status` — Получение текущего состояния сервера, имени хоста и списка подключенных устройств.
- `GET /api/history` — Получение последних записей буфера обмена и переданных файлов.
- `POST /api/clipboard` — Запись текста в системный буфер обмена Windows.
  - Тело запроса: `{"text": "строка"}`
  - Заголовок: `Content-Type: application/json`
- `POST /api/upload` — Потоковая загрузка файла (`multipart/form-data`).
- `GET /api/download/:id` — Скачивание файла с поддержкой Range-запросов (HTTP 206 Partial Content).

## Сборка и запуск

### Системные требования

- **Node.js** версии 20 или выше
- **Rust & Cargo** версии 1.78 или выше (MSVC toolchain для Windows)

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

Для запуска десктопного приложения в режиме разработки с горячей перезагрузкой:

```bash
npm run build
npm run tauri:dev
```

### Сборка исполняемого файла

Сборка оптимизированного автономного бинарного файла и установщика для Windows:

```bash
npm run build
npm run tauri:build
```

Результаты сборки размещаются в каталоге:
- Автономный бинарный файл: `src-tauri/target/release/localdrop.exe`
- Установщик NSIS: `src-tauri/target/release/bundle/nsis/`

## Интеграция с iOS Shortcuts

Для отправки содержимого буфера обмена с iPhone в Windows без открытия браузера:

1. Создайте новую команду в приложении **Команды** (Shortcuts) на iOS.
2. Добавьте действие **«Получить буфер обмена»**.
3. Добавьте действие **«Получить содержимое URL»**:
   - **URL:** `http://<IP_АДРЕС_ПК>:52025/api/clipboard`
   - **Метод:** `POST`
   - **Заголовки:** `Content-Type: application/json`
   - **Тело запроса:** `JSON`
   - **Поле:** ключ `text`, значение — переменная *Буфер обмена*.
4. Назначьте вызов команды на жест «Касание задней панели» (Back Tap) или кнопку действия (Action Button) в настройках iOS.

## Безопасность

- Сервер принимает соединения исключительно внутри локальной подсети (LAN).
- Для предотвращения атак типа Directory Traversal все пути к файлам валидируются относительно базового каталога загрузок с проверкой канонических путей.
- Размер принимаемых JSON-тел ограничен в заголовках Axum.
- Ограничение размера истории исключает утечки оперативной памяти при интенсивном обмене.
