# LocalDrop 🚀

Удобный, легковесный инструмент для обмена данными и буфером обмена между **iPhone (iOS Safari / Shortcuts)** и **ПК (Windows)** по локальной сети Wi-Fi.

Построен на базе **Tauri v2 (Rust + Axum)** и **React + Tailwind CSS**.

---

## 🌟 Возможности

- 📋 **Двусторонний буфер обмена:**
  - **Windows &rarr; iPhone:** Автоматический перехват `Ctrl+C` на ПК. Текст мгновенно отправляется по WebSocket на iPhone и доступен в 1 клик.
  - **iPhone &rarr; Windows:** Отправка текста прямо из Safari или через **iOS Shortcuts (Команды)** — текст автоматически пишется в системный буфер Windows (`Ctrl+V` сразу работает в любом приложении).
- ⚡ **iOS Shortcut в 1 тап (Action Button / Back Tap):**
  - Поддержка быстрой отправки текущего буфера iPhone без открытия браузера (постукиванием по задней панели iPhone или нажатием Action Button).
- 📁 **Передача файлов и медиа:**
  - Отправка фото из галереи или файлов с iPhone на ПК без сжатия и без ограничений по размеру.
  - Файлы автоматически сохраняются в папку `Downloads/LocalDrop` на Windows.
  - Быстрое открытие папки или конкретного файла в Проводнике Windows прямо из интерфейса.
- 📱 **Мгновенный вход по QR-коду:**
  - Достаточно навести камеру iPhone на QR-код в окне Windows. Не требуется установка приложений из App Store или ввод паролей.
- 🕒 **История передач:**
  - Полная история текстов и файлов сохраняется на диске между перезапусками приложения.

---

## 🛠 Архитектура

- **Десктоп Windows:** Tauri v2 (Rust + WebView2). Нативное окно дашборда, фоновый поток отслеживания буфера (`arboard`), хранилище истории (`history.json`).
- **Локальный сервер:** Встроенный сверхбыстрый HTTP & WebSocket сервер на **Axum 0.8** (порт `52025`).
- **Веб-клиент для iPhone:** Адаптивное React PWA приложение, оптимизированное под сенсорное управление в Safari.

## 🚀 Запуск и сборка

### Требования
- **Node.js** (v18+)
- **Rust & Cargo** (1.78+)

### 1. Установка зависимостей
```powershell
npm install
```

### 2. Сборка веб-интерфейса
```powershell
npm run build
```

### 3. Запуск в режиме разработки (Tauri App)
```powershell
npm run tauri:dev
```
*Либо через CLI:*
```powershell
npx @tauri-apps/cli dev
```

### 4. Сборка автономного .exe файла для Windows
```powershell
npm run tauri:build
```
Готовый легковесный бинарник появится в `src-tauri/target/release/localdrop.exe`.

## ⚡ Настройка быстрой команды iOS (Shortcuts)

Чтобы отправлять буфер с iPhone на ПК за полсекунды (например, по двойному постукиванию по задней крышке):

1. Откройте приложение **Команды** на iPhone и создайте новую команду.
2. Добавьте действие **«Получить буфер обмена»**.
3. Добавьте действие **«Получить содержимое URL»**:
   - **URL:** `http://<IP_ВАШЕГО_ПК>:52025/api/clipboard`
   - **Метод:** `POST`
   - **Заголовки:** `Content-Type: application/json`
   - **Тело запроса:** `JSON`
   - **Поле:** `text` &rarr; выберите переменную *«Буфер обмена»*.
4. В настройках iPhone перейдите в *Универсальный доступ &rarr; Касание &rarr; Касание задней панели* и назначьте эту команду на «Двойное касание».
